# Обновления Крилессы

**1.2.5 «Пока горят звёзды»**

Слышишь знакомые три ноты? В меню их играет шкатулка. На старой дамбе мелодию ведёт виолончель, а у шлюзов вступают ударные.

Звёзды Атласа теперь спрятаны далеко от старта. Ищи их по золотому свету на тропе.

При запуске игры с интернетом появится обновление. Нажми «Перезапустить», когда оно загрузится.
