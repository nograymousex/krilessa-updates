# Крилесса – обновления

Канал обновлений игры «Крилесса: Спасение Рыжовой». Приложение само проверяет
этот репозиторий при запуске.

- `latest.txt` – последняя версия (подписана ключом разработчика, без подписи игра ничего не ставит)
- `bundles/game-N.zip` – файлы игры для обновления без переустановки
- `apk/` – приложение целиком

Установить вручную: скачай самый новый файл из папки `apk/` и открой его на телефоне.
