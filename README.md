# Обновления Крилессы

**1.2.2 «По ту сторону дамбы»**

В восьмой главе Рыжовая находит колокол без языка. Пять стражей охраняют шлюзы, а на дне водохранилища ждёт Звонарка. У каждого стража три стадии боя, у Звонарки четыре.

На карте появились соляные отмели, верхний водосброс, туманные причалы и два подъёмных моста. Стрелка показывает направление, расстояние видно рядом с героиней.

При запуске с интернетом игра сама предложит обновление. Нажми «Перезапустить», когда загрузка завершится.
