# Обновления Крилессы

**1.2.0 «До первого света»**. Восьмая глава открывается после седьмой. В совместной игре сохранение остаётся у хозяйки и гостей.

При запуске с интернетом игра сама предложит обновление. Нажми «Перезапустить», когда загрузка завершится.

Приложение проверяет подпись `latest.txt` и загружает игровой пакет из `bundles/`. Полные сборки хранятся в `apk/`.
